# Stav

WORLD 8 — Web a DOM je dokončen.

# Lekce

HTML a DOM, `querySelector`, vlastnosti prvku, click/input a Boss Mini Web App.

# Didaktická cesta

Student nejdřív mění existující HTML prvek, potom ho vybírá selector-em, reaguje na událost a nakonec spravuje stav malé aplikace v poli.

# Nové koncepty

DOM, `document.querySelector`, `textContent`, `style`, `addEventListener`, `value`, `createElement`, `appendChild` a `innerHTML` při vykreslení známého vlastního obsahu.

# Opakované starší koncepty

Proměnné, `if`, funkce, pole, `for` cyklus a stav programu.

# Aktivity

PREDICT, EXPERIMENT, BUG HUNT, QUICK QUIZ, MISSION, BONUS a BOSS.

# Mission

Tři Mission scaffoldy jsou samostatně spustitelné přes oficiální WebDev template a obsahují pouze problémově formulovaná TODO.

# Boss

Vysílač úkolů spojuje HTML, DOM událost, pole, funkci vykreslení a cyklus.

# Validace

Prošla po rozšíření validátoru o WebDev import pro `08-web` a obecnou kontrolu Mission scaffoldů.

# Exporter

Oficiální LiaScript Exporter prošel pro všechny čtyři lekce.

# Regresní kontrola

Bez task listů, `[[...]]`, párových HTML wrapperů, lokální typografie a zakázaných `section` tagů.

# Známá omezení

Automatický Exporter neověří klikání, izolaci WebDev výstupů ani vzhled v navigaci; to zůstává pro manuální Preview po publikování větve.

# Ruční test

Spuštění příkladů, editace kódu, kliknutí, input, prázdný input, seznam úkolů, details, česká diakritika, Run/Stop a úzký viewport.
