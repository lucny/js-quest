# Stav

WORLD 2 — Decisions je vytvořen ve větvi `experimental/world2`.

# Vytvořené lekce

Čtyři lekce v `02-decisions/` vedou od booleanového výrazu k autonomnímu objektu.

# Didaktická návaznost

Odletění objektu z WORLD 1 vede k otázce o poloze, potom k `if`, odrazu, logice a zóně.

# Nové JavaScriptové koncepty

Porovnání, `true`/`false`, booleanový výraz, `if`, `else`, `||`, `&&` a `!`.

# Použité typy aktivit

PREDICT, EXPERIMENT, COMPLETE CODE, BUG HUNT, QUICK QUIZ, MISSION, BONUS, BOSS a FLAG.

# Boss

Smart Ball kombinuje pohyb v obou osách, čtyři hranice a aktivní zónu.

# Technické ověření

Každá lekce byla po vytvoření ověřena lokálním validátorem a oficiálním LiaScript Exporterem.

# Výsledky validace

Závěrečná validace je uvedena v předávacím výstupu.

# Výsledky LiaScript Exporteru

Exporter úspěšně zpracoval všechny čtyři lekce do dočasných JSON souborů.

# Známá omezení

Import sdílených maker používá veřejnou raw URL; výsledný renderer vyžaduje po pushi ruční Preview kontrolu.

# Co vyžaduje ruční vizuální test

Použijte `WORLD2-TEST.md`, zejména kvízy, `details`, canvas, Stop a font v navigaci.

# Doporučený další krok

Pushnout větev, projít WORLD 2 v LiaScript Preview a zaznamenat pozorování studentů.
