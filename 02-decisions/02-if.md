# WORLD 2 — Program se rozhoduje

@JSQ.world(2, Decisions)

> V minulé lekci kulička dokázala zjistit, že je za pravým okrajem. Teď jí dáme reakci.

---

## ENTRY — Odpověď true ještě nic nezmění

```js
let x = 80;
let speed = 3;

p5.setup = function () { p5.createCanvas(600, 300); };
p5.draw = function () {
  p5.background(245);
  p5.circle(x, 150, 40);
  x += speed;
};
```
@P5.eval

Kulička odletí. Otázka `x > p5.width` umí zjistit proč, ale program zatím nemá instrukci pro odpověď `true`.

---

## PREDICT — Co změní záporná rychlost?

@JSQ.predict
> **❓ PREDICT** @JSQ.xp(1)
>
> Je-li `speed = 3`, co způsobí příkaz `speed = -speed`?

[( )] rychlost se nastaví na 0
[(X)] rychlost bude -3 a kulička pojede doleva
[( )] kulička se zvětší
[( )] hodnota `x` se hned nastaví na -3

---

## EXPERIMENT — Reakce až za hranou

@JSQ.experiment
> **🧪 EXPERIMENT**
>
> Vlož do `draw()` níže uvedený blok. Spusť program a sleduj okamžik, kdy se směr obrátí.

```js
if (x > p5.width) {
  speed = -speed;
}
```

Podmínka je otázka v závorkách. Příkazy ve složených závorkách se provedou jen tehdy, když je odpověď `true`.

---

## LEARN — Jedna otázka, jedna reakce

```js
if (x > p5.width) {
  speed = -speed;
}
```

Čti to takto: „Jestliže je `x` větší než šířka canvasu, změň znaménko rychlosti.“ Když je odpověď `false`, blok se přeskočí.

```js

p5.setup = function () { p5.createCanvas(600, 300); };
p5.draw = function () {
  p5.background(245);
  p5.circle(x, 150, 40);
  x += speed;

  if (x > p5.width) {
    // TODO
  }
};
```

## BUG HUNT — Blok na špatném místě

@JSQ.bug
> **🐞 BUG HUNT** @JSQ.xp(2)
>
> Proč se rychlost mění při každém snímku, i když kulička ještě není u okraje?

```js
if (x > p5.width) {
}
speed = -speed;
```

<details><summary>Pomoc po vlastním pokusu</summary>

Příkaz reakce musí být mezi složenými závorkami bloku `if`.

<details><summary>Řešení</summary>

```js
if (x > p5.width) {
  speed = -speed;
}
```

</details></details>
