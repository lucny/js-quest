# Stav

WORLD 9 — Final Quest je dokončen.

# Lekce

Volba problému, mapa projektu, MVP, debugging a Final Quest.

# Didaktická cesta

Student nepoznává nový základní koncept. Vybírá problém, rozkládá jej na části, vytváří nejmenší funkční průchod, diagnostikuje chybu a samostatně dokončuje projekt.

# Nové koncepty

Žádné zásadní nové JavaScriptové koncepty. Nový je pouze pracovní postup autora projektu.

# Opakované starší koncepty

Proměnné, podmínky, cykly, funkce, pole, objekty, stav, p5 interakce a DOM volba z WORLD 8.

# Aktivity

PREDICT, EXPERIMENT, BUG HUNT, QUICK QUIZ, MISSION, BONUS, BOSS a FLAG.

# Mission

Vizitka projektu, mapa systému a MVP sběru jsou runnable scaffoldy s 1–3 problémově formulovanými TODO a postupnou pomocí.

# Boss

Final Quest má konkrétní kvalitativní kritéria, ale nenařizuje žánr ani hotové řešení. Student může volit p5 nebo DOM cestu.

# Validace

Prošla; navíc byla před validací opravena čárka v objektovém scaffoldu, aby výchozí Mission zůstala syntakticky validní.

# Exporter

Oficiální LiaScript Exporter prošel pro všech pět lekcí.

# Regresní kontrola

Bez task listů, `[[...]]`, párových HTML wrapperů, lokální typografie a zakázaných `section` tagů.

# Známá omezení

Final Quest lze obsahově a vizuálně ověřit až při práci konkrétního studenta v LiaScript Preview.

# Ruční test

Spuštění scaffoldů, šipky, klik, skóre, details, česká diakritika, navigace, Run/Stop, dark mode a úzký viewport.
