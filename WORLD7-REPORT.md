# Stav

WORLD 7 — Interaction je dokončen.

# Lekce

Myš, kliknutí a stav, klávesnice a Boss Micro Game.

# Didaktická cesta

Program nejprve čte vstup myši, potom událostí mění stav a nakonec reaguje na klávesnici v herním pravidle.

# Nové koncepty

`mouseX`, `mouseY`, `mousePressed`, `keyIsDown`, stav a skóre.

# Aktivity

PREDICT, EXPERIMENT, BUG HUNT, QUICK QUIZ, MISSION a BOSS.

# Mission

Všechny jsou runnable scaffoldy.

# Boss

Micro Game spojuje objekty, podmínky, stav, skóre a vstup.

Prošla.
